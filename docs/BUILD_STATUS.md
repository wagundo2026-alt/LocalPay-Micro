# LocalPay Micro build status

This repository contains the deployment skeleton for the hackathon demo. The full multi-route Next.js / Flask / Supabase source is available in the accompanying `localpay-micro-built.zip` project deliverable. **The repository does not yet contain all source files.** Do not deploy it as a complete application yet.

Payments are demo-only; no live provider is configured. Keep `ENABLE_DEMO_PAYMENTS=false` outside an isolated demonstration. Never commit Supabase service keys.
